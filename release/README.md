# Release builds

Prebuilt ZapWise v0.5.0 APKs (app versionCode 9).

| File | Contents | Size |
|---|---|---|
| `ZapWise-0.5.0.apk` | Universal build (arm, arm64, x64). Installs on any recent Android phone. | ~61 MB |
| `ZapWise-0.5.0-arm64.apk` | arm64-only build, for most physical phones. Smaller. | ~26 MB |

These are debug-signed, for sideloading and testing. To build from source, see the root `README.md`,
or push to GitHub and use the "Build APK" workflow under the Actions tab.
